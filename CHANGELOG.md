# Changelog

## 0.1.0 - 2026-09-20

- Added installable `captivate` CLI with extract, render, analyze, run, and doctor commands.

- Added optional local Ruffle/Playwright rendering and standalone MP4 analysis.
- Added offline tests, packaging metadata, CI, and operational documentation.
